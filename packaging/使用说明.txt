配额统计 QuotaChecker — 便携版使用说明
============================================================

【怎么启动】
双击本目录下的「启动 QuotaChecker.cmd」即可。
程序本体放在 app 子目录里（这样目录看起来才干净）；直接双击
app\QuotaChecker.exe 也能运行。

【系统要求】
Windows 10 1809 (17763) 及以上 / Windows 11，64 位。
无需安装 .NET 运行时，也无需安装 Windows App SDK —— 依赖都已打包在本目录内。


【第一次使用】
1. 点「添加密钥」
2. 名称随便填；接口地址填你的中转站域名（默认 https://4sapi.com）
3. 粘贴 API Key（sk- 开头）
4. 点「添加并查询」，程序会自动查询该密钥的配额消耗并换算成人民币

可以重复添加多个密钥，顶部卡片会汇总所有「已启用」密钥的累计消耗。


【关于倍率与换算】
人民币 = 配额 ÷ 500000 × 站点倍率

默认倍率是 1，即官方计价 1 美元 = 1 元（4sapi 的基础汇率）。
如果你的分组是 6 倍率，把界面上「站点倍率」改成 6 即可，
程序会自动保存并重新计算所有金额。


【密钥安全】
API Key 使用 Windows DPAPI 加密，只有当前 Windows 账号能解密，
不会以明文形式存盘，也不会发送到除你自己填写的中转站以外的任何地方。

存放位置：%LOCALAPPDATA%\QuotaChecker\keys.json
（界面右下角会显示这个路径）

换电脑或换 Windows 账号后无法解密，需要重新添加密钥。


【卸载】
直接删除本目录即可。
如果还想清除密钥记录，再删除 %LOCALAPPDATA%\QuotaChecker 目录。


【常见问题】
- 提示「无效的令牌」：检查 API Key 是否复制完整（sk- 开头）、是否已被禁用
- 提示「无法连接」：检查接口地址是否正确、网络是否可达
- 提示「接口返回 404」：接口地址只需填站点根域名，
  程序会自动补上 /api/usage/token
- 想统计所有密钥：列表左侧的勾选框要勾上，未勾选的密钥不计入总计
